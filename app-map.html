TRIGGER on_auth_user_created

  • Срабатывает: AFTER INSERT ON auth.users
  • Действие: создаёт запись в profiles с ролью user
  • SECURITY DEFINER — выполняется от имени владельца функции

FUNCTION confirm_user_email()

  • Аргумент: user_email TEXT
  • Обновляет email_confirmed_at в auth.users
  • Вызывается администратором при создании пользователя

FUNCTION delete_user_by_admin()

  • Аргумент: target_user_id UUID
  • Удаляет из: profiles → refresh_tokens → identities → auth.users
  • Проверяет роль admin вызывающего

Потоки данных

Как данные перемещаются между клиентом и Supabase

sequenceDiagram autonumber actor U as Пользователь participant B as Браузер

ILIKE '%подшипник%' PG-->>S: parts[] S-->>B: parts[] с именами цехов и линий B-->>U: Результаты поиска

READ Операции чтения

  • workshops — список всех цехов (Dashboard, Sidebar)
  • lines — линии конкретного цеха (WorkshopPage)
  • parts — запчасти конкретной линии (LinePage)
  • parts — поиск по name/description (Layout)
  • profiles — список пользователей (AdminPage)
  • app_versions — последняя версия APK (Sidebar)
  • auth.getSession() — текущая сессия (useAuth)

WRITE Операции записи

  • INSERT — создание цехов, линий, запчастей, пользователей
  • UPDATE — редактирование цехов, линий, запчастей, ролей
  • DELETE — удаление цехов, линий, запчастей (admin)
  • storage.upload — загрузка фото, файлов, APK
  • rpc() — confirm_email, delete_user, reset_password
  • auth.signUp — создание пользователя (adminApi)
  • auth.updateUser — смена пароля
